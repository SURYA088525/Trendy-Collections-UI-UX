# Trendy Collections — UI/UX Design 🎨

## About the Project
Trendy Collections is a beginner UI/UX design project inspired by my family's saree business. I created this concept to explore the fundamentals of e-commerce app design and practice designing user-friendly shopping experiences using Figma.

## Project Goals
- Explore basic e-commerce app design
- Practice visual hierarchy and screen layout
- Learn UI/UX design through hands-on practice
- Create a clickable prototype in Figma

## Tools
- Figma
- UI/UX Design Fundamentals
